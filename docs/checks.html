ConfigChief使い方シートと列チェックパックの書き方GitHub

チェックの一覧

このページは、プログラムが使っている定義から作っています（go run ./cmd/docgen）。手で直さないでください。

  • 重大度: E = エラー、W = 警告、I = 情報。「指定」= 案件のルールに書いた重大度
  • 頭の字: V = 値、X = 対向（2 台の間）、G = 生成、M = 移行（旧との違い・対応）、S = お客様の一覧、L = 投入ログと反映確認
ID重大度内容
V-101E必須の値が空
V-102E値の形式が型に合わない
V-103E値が範囲の外
V-104E選択肢にない語
V-105E行のキーが重複している
V-106E参照先がない（ACL 名・IF 名・回線監視の番号など）
V-107E「機器」列のホスト名が機器シートにない。@グループ名 に当たる機器が 1 台もない
V-108I定義にない見出しがある（自由列として読んだ）
V-109E機器シートのメーカーに当たるパックがない
V-110W値に全角の英数字、前後の空白、制御文字が含まれる
V-111EIF 名が、機種のポート一覧にも論理 IF の書き方にも当たらない
V-112E生成先のメーカーで書けない語
V-113I「明示」列が空のため、生成先の既定値で書き出す
V-114W機種が空、または機種の定義がない
V-115W参照先がないが、参照先の表をその機器のメーカーパックがまだ読まない
V-201E同じ機器・同じ VRF の中で、IF のサブネットが重なっている
V-202W案件の中で同じ IP アドレスが複数の IF に付いている
V-203EIF のアドレスがネットワークアドレスかブロードキャストアドレス
V-204Wスタティック経路のネクストホップが、その機器のどの IF のサブネットにも入らない
V-205E仮想 IP が、その IF のサブネットに入らない
V-206Eホスト名に使えない文字がある・長すぎる
V-207Eルータ ID（OSPF・BGP）が案件の中で重複している
V-208I有効な IF の説明が空
V-209Eハッシュ化された秘密の値を、別メーカーの機器に引き継ごうとしている
V-210WACL・プレフィックスリスト・回線監視が、定義されているがどこからも使われていない
V-211WACL に行が 1 つもない。permit の行が 1 つもない
V-212WTCP MSS 調整の値が MTU − 40 より大きい
V-213EDHCP の配布範囲・デフォルトルータがネットワークの外。配布範囲が IF のアドレスを含む
V-214Wスタティック経路・冗長化が参照する回線監視の送信元 IF が無効
V-215EIPsec の方式が tunnel_if なのにトンネル IF がない。policy なのに対象通信の行がない
V-216W弱い暗号（des・md5・dh1・dh2・dh5）を使っている
V-217EPPPoE の論理 IF・物理 IF がインタフェース表にない
V-218W秘密の値が仮の値のまま
X-300I相手の機器が案件の中にない（管理外）
X-301WIPsec・トンネル: 相手アドレスは案件の中の機器のものだが、相手側に対になる行がない
X-302EIPsec: IKE の版、モードが両端で違う
X-303EIPsec: IKE の暗号・ハッシュ・DH グループが両端で違う
X-304EIPsec: ESP の暗号・ハッシュ・PFS が両端で違う
X-305EIPsec: 事前共有鍵が両端で違う
X-306EIPsec: 自分の ID と、相手が期待する相手の ID が合わない
X-307EIPsec: 対象通信が両端で鏡写しになっていない
X-308WIPsec: 有効時間が両端で違う
X-309IIPsec: 相手監視・NAT 越えの設定が片側だけ
X-311Eトンネル: 送信元と宛先が両端で鏡写しになっていない
X-312Eトンネル: 種類・鍵が両端で違う
X-313Eトンネル: 両端のトンネル IF のアドレスが同じサブネットにない
X-314Wトンネル: MTU・監視の設定が両端で違う
X-321EBGP: 相手 AS 番号が、相手機器の AS 番号と違う
X-322EBGP: 片側にしかネイバーの行がない
X-323EBGP: パスワードが両端で違う・片側だけ
X-324WBGP: 送信元 IF の指定と、相手が指すアドレスが合わない。マルチホップの指定が片側だけ
X-325IBGP: タイマーが両端で違う
X-331EOSPF: 同じサブネットの IF で、エリアが違う
X-332EOSPF: Hello・Dead 間隔が違う
X-333EOSPF: 網の種類が違う
X-334EOSPF: 認証の方式・鍵番号・鍵が違う
X-335EOSPF: エリアの種類（stub・nssa）が違う
X-336WOSPF: IF の MTU が違う
X-337WOSPF: 片側だけ受動になっている
X-338IOSPF: 同じサブネットで、片側だけ OSPF が有効
X-341EVRRP・HSRP: 同じサブネット・同じグループ番号で、仮想 IP が違う
X-342EVRRP・HSRP: 方式・版が違う
X-343WVRRP・HSRP: 優先度が同じ
X-344EVRRP・HSRP: 認証が違う
X-345WVRRP・HSRP: 間隔が違う
X-346WVRRP・HSRP: グループに機器が 1 台しかない
X-351W同じサブネットの IF どうしで、プレフィックス長・MTU が違う
G-601Eテンプレートの実行エラー
G-602E設計データに値があるのに、生成に使われなかった
G-603E語の対応がない
G-604E往復の不一致（生成したコンフィグを取り込み直した結果が、設計データと違う）
G-605W生成したコンフィグに、取り込み直しで未対応になる行がある
G-606E生成先のメーカーで必要な値が空
G-607E機種が対応していない機能を使っている
G-608E追加コンフィグの実行エラー
G-609W追加コンフィグの行が、パックが生成した行と二重になっている
G-610指定案件のルール: 含むべき行がない
G-611指定案件のルール: 含んではいけない行がある
G-612指定案件のルール: 式が偽・値が重複・値がそろっていない
G-613E出力ファイル名が重複する・ファイル名に使えない文字がある
G-614Wパックが、このメーカーの書き方に置き換えて書いた設定がある
M-403E旧にあって新にない行
M-404W新にあって旧にない行
M-405W旧と新で値が違うセル
M-406EIF 対応が決まっていない旧 IF がある
M-407E機器対応が決まっていない旧機器がある
M-408E複数の旧 IF が、同じ新 IF に対応している
S-501Wお客様の一覧にあって、パラメータブックにない行
S-502Iパラメータブックにあって、お客様の一覧にない行
S-503Eお客様の一覧とパラメータブックで値が違う
S-504Wお客様の一覧の値が読めなかった
S-505Iお客様の一覧のファイルが、前回の読み込みから変わった
L-701E機器に弾かれた行（エラーメッセージと、その直前のコマンド）
L-702Wログのコマンドの並びが、生成したコンフィグと合わない（別の版を流した疑い）
L-703Wログに現れたコマンドが、生成したコンフィグより少ない（途中で切れた疑い）
L-704I機器の警告メッセージ
L-705Eログのプロンプトのホスト名と、流したコンフィグのホスト名・機器の対応が合わない（機器の取り違えの疑い）
R-801Eパラメータブックにあるが、機器の設定にない行
R-802W機器の設定にあるが、パラメータブックにない行
R-803Eパラメータブックと機器の設定で値が違う
R-804E追加コンフィグの行が、機器の設定に見つからない
R-805I機器の設定に未対応の行があり、追加コンフィグにも当たらない
R-806Eログのホスト名が、案件のどの機器にも当たらない・別の機器のものである
R-807I秘密の値は、機器側でハッシュ化されているため比べられなかった
