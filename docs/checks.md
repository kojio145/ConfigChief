# チェックの一覧

このページは、プログラムが使っている定義から作っています（`go run ./cmd/docgen`）。手で直さないでください。

- 重大度: E = エラー、W = 警告、I = 情報。「指定」= 案件のルールに書いた重大度
- 頭の字: V = 値、X = 対向（2 台の間）、G = 生成、M = 移行（旧との違い・対応）、S = お客様の一覧、L = 投入ログと反映確認

| ID | 重大度 | 内容 |
|---|---|---|
| V-101 | E | 必須の値が空 |
| V-102 | E | 値の形式が型に合わない |
| V-103 | E | 値が範囲の外 |
| V-104 | E | 選択肢にない語 |
| V-105 | E | 行のキーが重複している |
| V-106 | E | 参照先がない（ACL 名・IF 名・回線監視の番号など） |
| V-107 | E | 「機器」列のホスト名が機器シートにない。@グループ名 に当たる機器が 1 台もない |
| V-108 | I | 定義にない見出しがある（自由列として読んだ） |
| V-109 | E | 機器シートのメーカーに当たるパックがない |
| V-110 | W | 値に全角の英数字、前後の空白、制御文字が含まれる |
| V-111 | E | IF 名が、機種のポート一覧にも論理 IF の書き方にも当たらない |
| V-112 | E | 生成先のメーカーで書けない語 |
| V-113 | I | 「明示」列が空のため、生成先の既定値で書き出す |
| V-114 | W | 機種が空、または機種の定義がない |
| V-115 | W | 参照先がないが、参照先の表をその機器のメーカーパックがまだ読まない |
| V-201 | E | 同じ機器・同じ VRF の中で、IF のサブネットが重なっている |
| V-202 | W | 案件の中で同じ IP アドレスが複数の IF に付いている |
| V-203 | E | IF のアドレスがネットワークアドレスかブロードキャストアドレス |
| V-204 | W | スタティック経路のネクストホップが、その機器のどの IF のサブネットにも入らない |
| V-205 | E | 仮想 IP が、その IF のサブネットに入らない |
| V-206 | E | ホスト名に使えない文字がある・長すぎる |
| V-207 | E | ルータ ID（OSPF・BGP）が案件の中で重複している |
| V-208 | I | 有効な IF の説明が空 |
| V-209 | E | ハッシュ化された秘密の値を、別メーカーの機器に引き継ごうとしている |
| V-210 | W | ACL・プレフィックスリスト・回線監視が、定義されているがどこからも使われていない |
| V-211 | W | ACL に行が 1 つもない。permit の行が 1 つもない |
| V-212 | W | TCP MSS 調整の値が MTU − 40 より大きい |
| V-213 | E | DHCP の配布範囲・デフォルトルータがネットワークの外。配布範囲が IF のアドレスを含む |
| V-214 | W | スタティック経路・冗長化が参照する回線監視の送信元 IF が無効 |
| V-215 | E | IPsec の方式が tunnel_if なのにトンネル IF がない。policy なのに対象通信の行がない |
| V-216 | W | 弱い暗号（des・md5・dh1・dh2・dh5）を使っている |
| V-217 | E | PPPoE の論理 IF・物理 IF がインタフェース表にない |
| V-218 | W | 秘密の値が仮の値のまま |
| X-300 | I | 相手の機器が案件の中にない（管理外） |
| X-301 | W | IPsec・トンネル: 相手アドレスは案件の中の機器のものだが、相手側に対になる行がない |
| X-302 | E | IPsec: IKE の版、モードが両端で違う |
| X-303 | E | IPsec: IKE の暗号・ハッシュ・DH グループが両端で違う |
| X-304 | E | IPsec: ESP の暗号・ハッシュ・PFS が両端で違う |
| X-305 | E | IPsec: 事前共有鍵が両端で違う |
| X-306 | E | IPsec: 自分の ID と、相手が期待する相手の ID が合わない |
| X-307 | E | IPsec: 対象通信が両端で鏡写しになっていない |
| X-308 | W | IPsec: 有効時間が両端で違う |
| X-309 | I | IPsec: 相手監視・NAT 越えの設定が片側だけ |
| X-311 | E | トンネル: 送信元と宛先が両端で鏡写しになっていない |
| X-312 | E | トンネル: 種類・鍵が両端で違う |
| X-313 | E | トンネル: 両端のトンネル IF のアドレスが同じサブネットにない |
| X-314 | W | トンネル: MTU・監視の設定が両端で違う |
| X-321 | E | BGP: 相手 AS 番号が、相手機器の AS 番号と違う |
| X-322 | E | BGP: 片側にしかネイバーの行がない |
| X-323 | E | BGP: パスワードが両端で違う・片側だけ |
| X-324 | W | BGP: 送信元 IF の指定と、相手が指すアドレスが合わない。マルチホップの指定が片側だけ |
| X-325 | I | BGP: タイマーが両端で違う |
| X-331 | E | OSPF: 同じサブネットの IF で、エリアが違う |
| X-332 | E | OSPF: Hello・Dead 間隔が違う |
| X-333 | E | OSPF: 網の種類が違う |
| X-334 | E | OSPF: 認証の方式・鍵番号・鍵が違う |
| X-335 | E | OSPF: エリアの種類（stub・nssa）が違う |
| X-336 | W | OSPF: IF の MTU が違う |
| X-337 | W | OSPF: 片側だけ受動になっている |
| X-338 | I | OSPF: 同じサブネットで、片側だけ OSPF が有効 |
| X-341 | E | VRRP・HSRP: 同じサブネット・同じグループ番号で、仮想 IP が違う |
| X-342 | E | VRRP・HSRP: 方式・版が違う |
| X-343 | W | VRRP・HSRP: 優先度が同じ |
| X-344 | E | VRRP・HSRP: 認証が違う |
| X-345 | W | VRRP・HSRP: 間隔が違う |
| X-346 | W | VRRP・HSRP: グループに機器が 1 台しかない |
| X-351 | W | 同じサブネットの IF どうしで、プレフィックス長・MTU が違う |
| G-601 | E | テンプレートの実行エラー |
| G-602 | E | 設計データに値があるのに、生成に使われなかった |
| G-603 | E | 語の対応がない |
| G-604 | E | 往復の不一致（生成したコンフィグを取り込み直した結果が、設計データと違う） |
| G-605 | W | 生成したコンフィグに、取り込み直しで未対応になる行がある |
| G-606 | E | 生成先のメーカーで必要な値が空 |
| G-607 | E | 機種が対応していない機能を使っている |
| G-608 | E | 追加コンフィグの実行エラー |
| G-609 | W | 追加コンフィグの行が、パックが生成した行と二重になっている |
| G-610 | 指定 | 案件のルール: 含むべき行がない |
| G-611 | 指定 | 案件のルール: 含んではいけない行がある |
| G-612 | 指定 | 案件のルール: 式が偽・値が重複・値がそろっていない |
| G-613 | E | 出力ファイル名が重複する・ファイル名に使えない文字がある |

| M-403 | E | 旧にあって新にない行 |
| M-404 | W | 新にあって旧にない行 |
| M-405 | W | 旧と新で値が違うセル |
| M-406 | E | IF 対応が決まっていない旧 IF がある |
| M-407 | E | 機器対応が決まっていない旧機器がある |
| M-408 | E | 複数の旧 IF が、同じ新 IF に対応している |
| S-501 | W | お客様の一覧にあって、パラメータブックにない行 |
| S-502 | I | パラメータブックにあって、お客様の一覧にない行 |
