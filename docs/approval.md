# ConfigChief を使うための申請用の説明

ソフトウェアの利用申請に使う 1 枚の説明です。ConfigChief は個人が作って MIT ライセンスで公開しているツールです。版ごとに変わる値（版・SHA-256・ウイルス検査の結果）はここに書きません。[リリースのページ](https://github.com/kojio145/ConfigChief/releases)で確かめてください。

ほかのページ: [使い方](manual.md) ・ [シートと列の一覧](tables.md) ・ [チェックの一覧](checks.md)

## 何をするツールか

ネットワーク機器（Cisco IOS / IOS-XE、NEC UNIVERGE IX、NEC QX シリーズ）のコンフィグ（テキスト）を読んで、メーカーによらない表（Excel のパラメータブック）にします。その表から、コンフィグ・チェック結果表・納品用のパラメータシートを作ります。機器には接続しません。ファイルを読んで、ファイルを書くだけのツールです。

## 動かし方

| 項目 | 内容 |
|---|---|
| 形 | exe 1 つ（`ConfigChief.exe`）。インストーラはありません。置いてダブルクリックで動きます |
| 要るもの | WebView2 ランタイム（Windows 11 には初めから入っています） |
| インストール | しません。スタートメニュー・サービス・常駐・自動起動の登録はありません |
| レジストリ | 書きません。読むのは、最新版の確認のときのプロキシの設定だけです |
| 管理者の権限 | 要りません |
| 消し方 | exe と、下の「書き込む場所」の `%APPDATA%\ConfigChief` フォルダを消すだけです |

## 書き込む場所

- 利用者が作った**案件フォルダ**の中（パラメータブック・作ったコンフィグ・レポート・操作の記録）
- `%APPDATA%\ConfigChief`（最近使った案件の一覧・画面の拡大率・窓の位置と大きさ・内部エラーの記録 `error.log`・画面の作業フォルダ）

ほかの場所には書きません。`error.log` に、コンフィグや表の値は入りません。

## 通信

- **ふだんは一切通信しません。** 起動したとき、案件を開いたとき、作業中にも通信しません。待ち受けのポートも開きません
- 例外は、画面の「バージョン情報」で、利用者が次のボタンを押したときだけです:
  - 「最新版を確認する」: GitHub の公開リリースの情報（`https://api.github.com/repos/kojio145/ConfigChief/releases`）を読みます
  - 「最新版をダウンロード」: 確認の窓で許可したときだけ、GitHub のリリースから `ConfigChief.exe` を取り、リリースに登録された SHA-256 と照合して、exe と同じフォルダ（書けなければ「ダウンロード」フォルダ）に保存します
- 送るのは、GitHub への問い合わせ（宛先と ConfigChief の版）だけです。**案件の中身・コンフィグ・表の値・利用者の名前は送りません**
- プロキシは、環境変数 `HTTPS_PROXY` か、Windows の設定に手動で入れたものを使います
- 「使い方」「GitHub」などのリンクは、決まった宛先を既定のブラウザで開くだけです（ConfigChief は読みに行きません）
- 通信するコードはこの 2 つのボタンの所だけにあり、そのことはソースコードの試験で毎回確かめています

## 確かめ方

- exe には電子署名がありません。初めて起動するとき、Microsoft Defender SmartScreen の警告が出ることがあります（「詳細情報」→「実行」で起動できます）
- 取った exe は、リリースのページの SHA-256 と比べて確かめられます。PowerShell で `Get-FileHash ConfigChief.exe` と打ちます
- 公開のたびに、exe を VirusTotal で検査しています。結果はリリースのページか作者に確かめてください。署名の無い exe は、機械学習の検出で誤検知が出ることがあります
- ソースコードはすべて公開しています（[GitHub](https://github.com/kojio145/ConfigChief)）。同じソースからは同じ exe ができます（公開側の自動ビルドで、Release の exe と SHA-256 が一致することを確かめています）

## 秘密の値の扱い

- パスワード・事前共有鍵などは、利用者が置いたコンフィグとパラメータブックに入っている値を、利用者の案件フォルダの中で扱います。ツールが外に出すことはありません
- 画面とチェック結果表では、秘密の値を伏せて出します（生成したコンフィグには書きます）
- 案件を人に渡すための書き出しは、パスワードで暗号化（AES-256-GCM）できます。秘密の値を外して書き出すこともできます
