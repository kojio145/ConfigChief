ConfigChief

ルータのコンフィグを、メーカーによらない Excel の表にする。表から、全台のコンフィグとチェック結果を出す。

旧機器のコンフィグを読んでパラメータブック（Excel）にし、その表から新しい機器のコンフィグ・提出用のチェック結果表・納品用のパラメータシートを出します。 同じ表から別メーカーのコンフィグも出せるので、Cisco IOS から NEC IX への書き換え（その逆も）に使えます。 exe 1 つで動き、インストールは不要です。外部とは一切通信しません。

ダウンロード（GitHub Releases） 使い方 ソースコード（GitHub）

v1.0.0。Windows 10 / 11（x64）。署名の無い exe のため、初めて起動するときに SmartScreen の警告が出ることがあります（「詳細情報」から「実行」）。MIT ライセンス・商用利用可。実機では確かめていません（同梱のパックはメーカーの公開コマンドリファレンスから作りました）。生成したコンフィグは、必ず検証機で確かめてから使ってください。

できること

コンフィグ → 表旧機器のコンフィグ（端末ログのままでも可）を読み、行ごとに「取り込み済み・無視・未対応」を色で出します。
表 → 全台のコンフィグExcel を直してボタン 1 つで、全台のコンフィグとチェック結果表を出します。2 回目からは前回からの変更一覧も。
別メーカーへの書き換え同じ表から Cisco IOS / NEC IX のどちらのコンフィグも出せます。書けない値・置き換えて書いた設定は、必ず指摘として出します。
チェック値の誤り、2 台の間の食い違い（IPsec・BGP・OSPF・VRRP・トンネル）、旧との違いを調べます。指摘は理由を付けて承認できます。
自己点検生成したコンフィグを読み直し、元の表と同じになることを毎回確かめます。
検証と投入の後検証機の投入ログから弾かれた行を探し、投入後の設定とパラメータブックの違いを出します。
納品物自分の書式の Excel のひな形に値を流し込んだ納品用パラメータシート、相手に渡すパラメータ表。
新規構築空のパラメータブックから 1 台目を作り、機器を複製して増やせます。
メーカーパック本体はメーカーを知りません。読み方・書き方はテキストのパックにあり、足したり直したりできます。
外部通信ゼロテレメトリなし・自動更新なし・待ち受けポートなし。閉域の作業端末での利用を想定した設計です。

対応している設定

機器の基本・インタフェース・スタティック経路・ユーザ・遠隔ログイン・NTP・syslog・SNMP・VRF・OSPF・BGP・VRRP / HSRP・ACL・プレフィックスリスト・NAT・回線監視・PPPoE・IPsec（IKEv1）・GRE・DHCP・QoS（Cisco の古い書き方も読みます）。対応していない設定は「未対応」として一覧に出し、追加コンフィグで運べます。

こんな場面に

  • 数十〜数百台のルータ更改で、旧コンフィグからパラメータシートを作り直す転記をやめたい
  • Cisco から NEC（またはその逆）に入れ替えるとき、書き換えの漏れと値の食い違いを機械的に見つけたい
  • IPsec や BGP の両端の値が合っているかを、全台まとめて確かめたい
  • 提出用のチェック結果と、変更の前後の一覧を、毎回同じ形で出したい

使い方

  1. Releases から zip をダウンロードして展開し、中の ConfigChief.exe を起動（インストール不要）
  2. 案件フォルダを作り、旧機器のコンフィグを input/old/ に置いて「取り込み」
  3. Excel で対応（旧ホスト名 → 新ホスト名・新メーカー、旧 IF 名 → 新 IF 名）を埋めて、パラメータブックにする
  4. 「生成とチェック」で、全台のコンフィグとチェック結果表が出ます

詳しくは 使い方、シートと列の一覧、チェックの一覧、メーカーパックの書き方 を参照してください。作った経緯と設計の考え方は Zenn の開発記 にまとめています。

English

ConfigChief reads router configurations into a vendor-neutral Excel workbook and writes configurations, a check report and delivery sheets back from it. The same workbook gives the configuration of either vendor (Cisco IOS / IOS-XE, NEC UNIVERGE IX), so it also serves for replacing routers across vendors. One portable Windows exe, no network access. The user interface and the documents are in Japanese. Not verified on real devices yet: check every generated configuration on a lab device. See the GitHub repository.
